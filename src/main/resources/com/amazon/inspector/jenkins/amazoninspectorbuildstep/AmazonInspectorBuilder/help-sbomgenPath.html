The full path to an inspector-sbomgen binary that you downloaded, such as /opt/inspector/inspector-sbomgen. The file must exist and be executable, and the path can contain only letters, numbers, spaces, periods, underscores, hyphens, colons and forward slashes. The plugin checks the path on the Jenkins controller but runs the binary on the machine that runs the build, so if the build runs on an agent, put the binary at the same path on both.

For more info: https://docs.aws.amazon.com/inspector/latest/user/cicd-jenkins.html
