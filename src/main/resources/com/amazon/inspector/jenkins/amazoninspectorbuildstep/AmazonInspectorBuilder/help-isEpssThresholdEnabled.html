EPSS threshold: Fails the build when any vulnerability has an EPSS score greater than or equal to the EPSS Threshold value. EPSS scores range from 0 to 1, so enter a value between 0 and 1, such as 0.6. If the value is empty, the check is skipped. Vulnerabilities without an EPSS score and CVEs in the CVE suppression list don't count.

For more info: https://docs.aws.amazon.com/inspector/latest/user/cicd-jenkins.html
